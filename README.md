# ALFA Conecta

**Remote support, simple and secure.** · *Suporte remoto, simples e seguro.*

ALFA Conecta is the remote support client used by [Alfa Contabilidade](https://remoto.alfacont.cloud) to assist its team and its
client companies. It is a **visible fork of [RustDesk](https://github.com/rustdesk/rustdesk)** (AGPL-3.0) with the Alfa
branding (name, icons, colors) and with the organization's own self-hosted server pre-configured, so a support session
needs no manual setup on the client's computer.

- Remote desktop control, file transfer and chat, end-to-end encrypted (RustDesk protocol).
- Connections go only through the organization's own server (`remoto.alfacont.cloud`); no third-party relay is used.
- Every session is shown to the person at the computer, who can see and end it at any time.
- Installs as a regular Windows/macOS application, with a standard uninstaller.

The source code of the client is this repository; the changes on top of RustDesk are limited to branding and
configuration and are generated by a script (see the commit history of the `alfaremoto` branch). The server-side
console is a separate project.
