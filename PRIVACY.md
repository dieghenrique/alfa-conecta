# Privacy policy — ALFA Conecta

*Português abaixo.*

ALFA Conecta will not transfer any information to other networked systems unless specifically requested by the user or
the person installing or operating it.

ALFA Conecta is installed by an organization (for example, Alfa Contabilidade) to provide remote support. The server it
connects to is chosen and operated by that organization and is fixed at installation. With that server — and only with
it — the application exchanges:

- **Connection data** needed for remote access: the device ID, network address and public key used to establish the
  encrypted session.
- **Device information**, so the organization can identify the computer it supports: computer name, operating system and
  version, logged-in user name, CPU and memory, and the application version.
- **Session records**: start and end time of each remote session, who connected and the type of session, and, when files
  are transferred during a session, the file names and sizes. The *content* of the screen, keyboard input and files is
  end-to-end encrypted and is not stored by the server.

No data is sent to the RustDesk project, to advertisers or to any other third party. The organization that installed the
application is responsible for the data on its server; contact it to request access or deletion. Uninstalling
ALFA Conecta stops all communication.

## Política de privacidade (português)

O ALFA Conecta não transfere informações para outros sistemas, exceto quando solicitado por quem o usa, instala ou opera.

O aplicativo é instalado por uma organização (por exemplo, a Alfa Contabilidade) para prestar suporte remoto e se conecta
somente ao servidor dessa organização, definido na instalação. Com esse servidor ele troca: dados de conexão (ID do
dispositivo, endereço de rede e chave usada na sessão criptografada); informações do computador (nome, sistema, usuário,
processador, memória e versão do aplicativo); e registros das sessões (início, fim, quem acessou, tipo de sessão e nomes e
tamanhos de arquivos transferidos). O conteúdo da tela, do teclado e dos arquivos é criptografado de ponta a ponta e não
fica guardado no servidor. Nenhum dado é enviado ao projeto RustDesk ou a terceiros. Para acesso ou exclusão dos seus
dados, fale com a organização que instalou o aplicativo. Desinstalar o ALFA Conecta encerra toda a comunicação.
